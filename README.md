# 💌 Special Invitation

Это готовый мини-сайт-приглашение из 3 страниц.

## Что уже работает

- кнопка «Не пойду» убегает от мышки;
- на телефоне она тоже убегает от касания;
- «Пойду» переводит на праздничную страницу;
- календарь позволяет выбрать дату;
- дата сохраняется локально;
- дата может отправляться в Google Таблицу.

# 🚀 Как подключить Google Таблицу

Это нужно сделать один раз.

### 1. Создай Google Таблицу

Создай обычную Google Таблицу, например:

`Наше свидание 💗`

Оставь первый лист как есть.

### 2. Открой Apps Script

В таблице:

**Расширения → Apps Script**

Удаляешь код, который там будет, и вставляешь содержимое файла `Code.gs` из этого архива.

Нажимаешь **Сохранить**.

### 3. Опубликуй скрипт

В Apps Script нажми:

**Развернуть → Новое развёртывание**

Тип:

**Веб-приложение**

Параметры:

**Выполнять от имени:** тебя

**У кого есть доступ:** Все

Нажми **Развернуть**.

Google попросит разрешения — разреши доступ к таблице.

После этого Google даст URL примерно такого вида:

`https://script.google.com/macros/s/XXXXXXXXXXXX/exec`

### 4. Вставь URL в сайт

Открой `index.html`.

Найди:

```js
const GOOGLE_SCRIPT_URL = 'ВСТАВЬ_СЮДА_URL_GOOGLE_APPS_SCRIPT';
```

И вставь вместо текста URL, который дал Google.

Например:

```js
const GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/XXXXXXXXXXXX/exec';
```

Сохрани файл.

# 🌐 Как загрузить на GitHub Pages

1. Создай новый GitHub repository.
2. Загрузи туда `index.html`.
3. Можно также загрузить свои картинки.
4. Открой:

**Settings → Pages**

5. В разделе Source выбери:

**Deploy from a branch**

6. Branch:

**main**

7. Folder:

**/ (root)**

8. Сохрани.

Через некоторое время GitHub даст ссылку вида:

`https://ТВОЙ_USERNAME.github.io/НАЗВАНИЕ_РЕПОЗИТОРИЯ/`

Эту ссылку уже можно отправлять человеку.

# 🖼️ Как поставить свои картинки

Сейчас на двух страницах стоят заглушки.

Самый простой вариант:

1. Положи картинку рядом с `index.html`.
2. Назови её, например, `first.jpg`.
3. В HTML замени блок-заглушку на:

```html
<img class="invite-image" src="first.jpg" alt="">
```

Для второй страницы аналогично:

```html
<img class="invite-image" src="second.jpg" alt="">
```

# ⚠️ Важный момент

Не вставляй сюда пароль от Google или какие-либо секретные ключи.

Для этой схемы они вообще не нужны.

Google Таблица будет хранить выбранную дату, а сайт будет отправлять туда только дату и время выбора.
